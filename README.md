# CODSOFT Java Development Internship

This repository contains the projects completed as part of my **Java Development Internship** at **CODSOFT**. These projects helped me strengthen my understanding of Java programming, Object-Oriented Programming (OOP), Swing GUI development, exception handling, and API integration.

---

## 📌 Tasks Completed

### 1️⃣ Number Guessing Game

A console-based game where the user attempts to guess a randomly generated number within a limited number of attempts.

#### Features

* Random number generation
* Input validation
* Limited attempts
* Score tracking
* Replay option
* Exception handling

#### Technologies Used

* Java
* OOP Concepts
* Exception Handling

---

### 2️⃣ Student Grade Calculator

A Java application that calculates total marks, percentage, grades, and final result based on marks entered by the user.

#### Features

* Marks validation
* Subject-wise grade calculation
* Total marks calculation
* Percentage calculation
* Overall grade generation
* Pass/Fail determination

#### Technologies Used

* Java
* Arrays
* Conditional Statements
* Exception Handling

---

### 3️⃣ ATM Interface

A Java Swing-based ATM simulation that allows users to perform banking operations through a graphical user interface.

#### Features

* Deposit money
* Withdraw money
* Check account balance
* Transaction history
* User-friendly GUI
* Error handling

#### Technologies Used

* Java
* Swing
* Event Handling
* OOP Concepts

#### Note

This project requires the **UserBank** class because it contains the following methods:

```java
addMoney(double amount)
takeMoney(double amount)
getBalance()
```

---

### 4️⃣ Currency Converter

A Java Swing application that converts one currency into another using real-time exchange rates obtained through API integration.

#### Features

* Live currency conversion
* Multiple currency support
* API integration
* User-friendly GUI
* Input validation
* Error handling

#### Technologies Used

* Java
* Swing
* REST API
* Networking (HttpURLConnection)

## 🚀 How to Run

### Clone the Repository

```bash
git clone https://github.com/your-username/CODSOFT-Java-Internship.git
```

### Navigate to Project Folder

```bash
cd CODSOFT-Java-Internship
```

### Compile Java Files

```bash
javac *.java
```

### Run a Project

```bash
java NumberGame
```

or

```bash
java StudentGradeCalculator
```

or

```bash
java ATMSystem
```

or

```bash
java MoneyExchangeApp
```
